# WATTSHIFT — Сделай город умнее!

**Играть:** https://wattshift-game.vercel.app

Web-релиз 1.0.0: один настоящий 3D-город, 17 ситуаций, три главы и финал. Нажми на здание с !, выбери решение, прочитай объяснение и продолжай. Установка Unity игрокам не нужна.

Прогресс и настройки сохраняются локально в браузере. Используй тот же браузер и адрес сайта; очистка данных сайта удаляет локальные сохранения.

Проверено: macOS 27.3, Chrome 155 и Firefox 159 — меню, первая задача, награда, повторное открытие и восстановление прогресса. В Chrome также проверены настройки, обновление сборки, камера и запуск WebAudio после клика. Полное прохождение 17 ситуаций проверено в Unity Play Mode. Автотесты: 104 Edit Mode, 18 Play Mode; после исправления единиц колёсика дополнительно 5/5 тестов камеры.

**MOBILE NOT TESTED на физических устройствах.** В эмуляции Chrome проверены Low по умолчанию, касание здания, карточка, награда, drag/pinch и обе ориентации. Safari и Windows/Edge не проверены; Safari WebDriver заблокирован выключенной настройкой Allow remote automation.

Короткая проверка на телефоне: открой сайт → выбери школу и решение → перейди дальше → перезапусти страницу. Проверь pan/pinch, закрытие карточки, прокрутку и поворот экрана.

Известно: Chrome выдаёт предупреждения WebGL INVALID_ENUM при запросе форматов; критических ошибок/видимых артефактов в проверенных сценариях нет. Звуковой API проверен, субъективное качество звука и длительная стабильность не оценивались.

Для разработки: Unity 6000.3.27f1 + Web Build Support, URP 17.3.0. Сборщик: `Wattshift.Editor.GateFiveBuild.BuildWebRelease` с активной целью WebGL. Упаковка в пустую папку: `python3 tools/stage_web_release.py Builds/G5/WebRelease`. Заголовки создаются по реальным файлам; Brotli без Decompression Fallback. Проверка HTTPS: `node tools/check_web_headers.cjs URL docs/evidence/web-1.0/payload.json report.json`.

Публичная папка: `release/web-deploy` (исключена из Git). Конфигурация сохранена в `release/vercel.json`; сборки, исходники Unity и служебные документы на хостинг не отправляются. Лицензии Kenney CC0 и Noto SIL OFL входят в THIRD_PARTY_NOTICES.txt.
