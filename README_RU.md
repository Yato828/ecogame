# WATTSHIFT — стартовый пакет для Codex

Это **инструкции и спецификация**, не собранная игра и не архив с готовыми 3D-моделями. Содержит план, промпты, реальные ссылки на источники ассетов, роли агентов, проверки качества. Ассеты должны быть загружены из указанных источников и проверены в Unity; файл `assets_manifest/sources.json` является перечнем источников, а не гарантией скачанных файлов.

## Запуск работы
1. Создай новую пустую папку `WATTSHIFT` и распакуй туда **содержимое** этого архива (в корне должны находиться `AGENTS.md`, `.agents/`, `docs/`, `prompts/`).
2. Открой папку в VS Code + Codex или через Codex CLI.
3. Прочитай `docs/GAME_DESIGN.md` и `docs/QUALITY_GATES.md`.
4. Отправь Codex текст из `prompts/START_CODEX.md`.
5. Попроси начать **только с Gate 0/1**. Дальнейшие этапы — только после проверки настоящего скриншота сцены в Unity.
6. Установи нужную версию Unity 6 в Unity Hub и укажи путь к Editor. Для Web-билда требуется соответствующий модуль Build Support.

## Отдельно про платформы
Web является первичной платформой. Windows/macOS — вторичными. iOS/Android browser проверяются отдельно на реальных устройствах. Нет обещания 100% совместимости со всеми устройствами.

## Структура
- `AGENTS.md` — короткие обязательные правила Codex
- `.agents/skills/*/SKILL.md` — 6 рабочих скиллов
- `docs/GAME_DESIGN.md` — игровые механики и миссии
- `docs/ARCHITECTURE.md` — компоненты и данные
- `docs/QUALITY_GATES.md` — этапы и запреты
- `docs/AGENT_TASKS.md` — роли, делегирование, токены
- `docs/PERFORMANCE.md` — оптимизация
- `assets_manifest/sources.json` — источники и лицензии
- `prompts/START_CODEX.md` — стартовый промпт
- `prompts/NEXT_STAGE.md` — шаблон следующей итерации
