# WATTSHIFT — G1: готово к визуальному одобрению

Позднейшее состояние: пользователь одобрил G1; управление G1.1 и первая миссия G2 описаны в [актуальном отчёте](G11_G2_REPORT.md). Ниже сохранены исходные результаты G1.

Дата: 7 ноября 2026, Europe/Minsk. **G0 PASS. G1 реализован и проверен в Unity, ожидает визуального одобрения пользователя. G2–G4 не начаты.** Это визуальный срез, а не готовая игра или проверенный Web-релиз.

## Что создано

Полноценная структура Unity-проекта находится прямо в корне workspace. Редактор **6000.3.27f1**, URP **17.3.0**, Input System **1.17.0**. ProjectSettings и первоначальные настройки рендера взяты из официального URP-шаблона установленного редактора; необходимые изменения выполнены редактором Unity. `Packages/manifest.json` и созданный Unity `packages-lock.json` сохранены. Официальный Input System включён локальным TGZ, полученным с `https://packages.unity.com/com.unity.inputsystem/-/com.unity.inputsystem-1.17.0.tgz`; лицензия находится внутри пакета. Остальные зависимости успешно разрешены UPM.

Сцена: `Assets/_WATTSHIFT/Scenes/CitySlice.unity`. В ней восемь разных настоящих зданий: шесть Suburban `building-type-a`–`building-type-f`, Commercial `building-e` в роли школы и `building-c` в роли поликлиники. Назначения школы/поликлиники заданы карточками: это подходящие универсальные модели, не специально смоделированные медицинские/учебные корпуса. Добавлены перекрёсток, переходы, сквер с деревьями и дорожками, четыре фонаря. Все видимые меши, включая основание диорамы, происходят из проверенных Kenney FBX; основание и газон используют настоящий `tile-low` с осознанным масштабированием/цветом материала. Примитивы используются только как невидимые BoxCollider для выбора зданий.

Четыре исходных пакета импортированы в `Art/Imported/<pack>/`, сохранены оригинальные лицензии и текстуры. Для сцены используются URP Lit и общие палитры 512×512, ортографическая камера, мягкие тени одного направленного источника, умеренная цветокоррекция. Рендер настроен Forward с MSAA4; дорогой шаблонный SSAO отключён. Освещение realtime; baked GI и LOD-бюджеты в этом этапе не проверялись.

Русский UI Toolkit-интерфейс показывает карточку выбранного объекта, отдельно отмечает защищённую поликлинику, поддерживает закрытие, клавиатурный перебор и адаптивную вертикальную компоновку. Управление: клик/касание — выбор; WASD/стрелки или перетаскивание — обзор; колесо/щипок — масштаб; Tab/Shift+Tab — здания; Esc — закрыть; Home — вернуть камеру. Физические сенсорные устройства ещё не тестировались.

## Исправленные ошибки и пределы проверки

Первый проход обнаружил ошибки компиляции неоднозначных enum/конструкторов в вспомогательных скриптах; они исправлены. Первый визуальный проход выявил совпадающие поверхности земли, неверный поворот дорог и их пересечение с торцевыми сегментами, ожидание шейдера с голубой заглушкой, перекрытие вертикальных панелей. Исправлены координаты/ориентация, ожидание шейдеров и адаптивный UI. Камера теста теперь сбрасывает и позицию, и внутреннюю цель после проверки pan.

Ошибка `UnityEditor.Search.SearchDatabase` возникала из-за немедленного входа теста в Play mode до создания поискового индекса. Исправление: запуск Play mode отложен до инициализации редактора; итоговый проход не содержит этой ошибки. В логах остаётся не блокирующее сообщение лицензирования `Access token is unavailable; failed to update`; затем Unity успешно разрешает entitlement и завершает Play mode. Ранние неудачные логи и изображения сохранены в `first-pass`, `second-pass`, `third-pass`, чтобы не скрывать историю проверок.

**Не выполнялись:** Web/Windows/macOS-сборки, браузерные тесты, реальные телефоны, тесты симуляции/сохранений, измерения памяти, загрузки и draw calls, остальные пропорции экрана. Web Build Support и Windows-модуль отсутствуют; для будущих соответствующих сборок их нужно установить. Полноценные quality tiers относятся к G4; уровни исходного шаблона не считаются проверенной системой качества WATTSHIFT.

## Открытие напрямую без Unity Hub

В macOS Terminal:

```sh
"/Applications/Unity/Hub/Editor/6000.3.27f1/Unity.app/Contents/MacOS/Unity" \
  -projectPath "/Users/yato/Downloads/WATTSHIFT_Codex_Starter_Kit"
```

Если редактор не восстановит сцену, открыть `Assets/_WATTSHIFT/Scenes/CitySlice.unity`, затем нажать Play. Для воспроизведения доказательств доступно меню `WATTSHIFT/Capture and verify G1`: оно запускает автоматическую проверку и **закрывает Editor по завершении**. Меню `Build visual slice` пересобирает сцену и может заменить ручную компоновку; его не требуется использовать для обычного просмотра.

Следующее действие: визуальное одобрение пользователем. **G2 не начинать до этого одобрения.**
