# Загрузка ассетов

Главные источники указаны в `assets_manifest/sources.json` и доступны на официальных сайтах. На страницах Kenney используй «Continue without donating» и затем скачай ZIP. Запиши оригинальные имена архивов и SHA-256. Лицензию сохраняй вместе с оригинальными файлами. Не нужно скачивать всю библиотеку Kenney.

Приоритет: Suburban + Roads + Commercial + Industrial. Nature Kit только после проверки графического стиля. UI и звуки можно подключить в G3. ambientCG — только для отдельных поверхностей, если стилизованным моделям действительно нужны дополнительные текстуры. Отклоняй реалистичные материалы, которые выглядят чужеродно на простых моделях.

Необходимые сцены и префабы: residential 6+, school/clinic represented by compatible exterior models or clearly labeled generic civic building, road network, LED lamps 4+, park/trees, solar and wind examples if appropriate. Соблюдай авторские лицензии каждого набора.
